# Scripts archivés

Scripts one-shot déjà exécutés en production (appliqueurs de migration,
backfills, nettoyages). Conservés pour référence et audit, mais **ne pas
relancer** sans relire : ils supposent l'état de la base au moment de
leur écriture.

Les scripts encore utiles au quotidien restent dans `scripts/`
(seed, magic-link, diagnostics, kill-db-zombies, apply-supabase-sql).
